# 新舊版輸出對拍(L3)之工具:雜湊整個輸出樹、前進式假時鐘、記錄請求,與先驗工具本身

> 本檔為 SKILL.md Step 3 第 6 點之細則.下列程式之邏輯於 2026-11-19 在 Windows、Node v24.22.1 以夾具實跑(三種變異、固定／前進式時鐘之對照皆照所列結果;貼入本檔時僅精簡排版).記錄請求之作法(第 3 節末)為提案端作法,未另行實跑.

**觸發**:重構或資料處理改動要做前後輸出 diff(L3);審查他人之對拍工具或「0 處不同」之結論.

**為何**:對拍之價值全在工具之鑑別力.只比回傳值與幾個已知資料夾之工具,對[不該寫之檔也寫出]、[少寫一檔]、[請求之標頭不同]皆回[0 處不同],稿內卻寫成[比對全部產物、0 處不同].**典型錯誤形狀**:擬稿者之對拍工具只比回傳值與三個已知資料夾,稿內寫[比對全部產物、0 處不同];審查者植入[不該寫之檔也寫出]之變異,該工具仍判 0 處不同;另一案之工具不比請求之標頭.

## 1. 雜湊整個輸出樹

**檔名清單一項、每檔之內容一項**(必要時加每檔之修改時間):新增、消失、改動之檔都須使結果改變.

```js
import fs from 'node:fs'
import path from 'node:path'
import crypto from 'node:crypto'

let hashTree = (dir) => {
    let rels = []
    let walk = (d) => {
        for (let e of fs.readdirSync(d, { withFileTypes: true })) {
            let fp = path.join(d, e.name)
            e.isDirectory() ? walk(fp) : rels.push(path.relative(dir, fp).split(path.sep).join('/'))
        }
    }
    walk(dir)
    rels.sort()
    let h = (b) => crypto.createHash('sha256').update(b).digest('hex')
    let perFile = Object.fromEntries(rels.map((r) => [r, h(fs.readFileSync(path.join(dir, r)))]))
    return { names: h(rels.join('\n')), perFile, all: h(JSON.stringify(perFile)) }
}
// 判相同:a.all === b.all && a.names === b.names;不同時逐檔比 perFile 列出差異之檔
```

## 2. 採信[0 處不同]之前,先驗工具本身

以三種變異各產一份輸出樹,工具**都須判為不同**,否則工具不可用:

| 變異 | 實測(夾具:2 檔之輸出樹) |
|---|---|
| 同版再跑(對照,應相同) | 判為相同 |
| 多寫一檔 | 判為不同 |
| 少寫一檔 | 判為不同 |
| 改一個數字 | 判為不同 |
| (誤例)只比 `a.txt` 之工具對[多寫一檔] | 判為相同(漏網) |

稿內對比對範圍之敘述(比了哪些、沒比哪些)須與工具實際所比者一致.

## 3. 時間與外部請求

- **假時鐘以子類別取代 `Date`,含逐次前進式**:固定時鐘抓不到[成功路徑多取了一次現在],前進式(每讀一次前進固定量)抓得到.實測:舊版取一次、新版取兩次(以第二次之值輸出),固定時鐘下輸出相同(漏網),前進式時鐘下輸出不同(抓到).

```js
let RealDate = Date
let installClock = (mode) => {            // mode: 'fixed' | 'step'
    let t = RealDate.UTC(2026, 10, 19, 0, 0, 0)
    class FakeDate extends RealDate {
        constructor(...a) { a.length === 0 ? super(mode === 'step' ? (t += 1000) : t) : super(...a) }
        static now() { return mode === 'step' ? (t += 1000) : t }
    }
    globalThis.Date = FakeDate
}
// 還原:globalThis.Date = RealDate;新舊兩版各自在同一時鐘初值下重跑,再比輸出
```

- **對外請求者,另記錄請求之參數與標頭**(把 `fetch` 或 HTTP 客戶端包一層,依序記下 `{ method, url, headers, body }`,新舊兩版之記錄陣列逐筆比對):只比參數之工具會漏掉標頭之差異.
