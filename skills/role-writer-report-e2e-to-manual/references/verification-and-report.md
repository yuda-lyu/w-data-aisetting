# 交付驗證與回報：手冊之核對判準、回報範本、裁示衛生

本檔為 SKILL.md §8 之作法。所有指令以專案根為工作目錄，路徑以佔位表示。

## 1. md 層核對

| 檢核 | 作法 | 判準 |
|---|---|---|
| 節數 | 數 `### ` 標題 | ＝已撰寫案例數 |
| 圖數 | 數圖片標籤（`src="pics/`） | ＝各案例可用圖數之和 |
| 圖題／表題 | 數「圖n 」「表n 」佔位（產 md 時尚未編號者為佔位字樣） | 圖題＝圖數；表題＝節數 |
| 殘留 | grep `{fig:`、未解析之 `{` | 0 |
| 用圖一致 | `report/pics/` 每張與標準圖夾同名檔比雜湊（標準圖變動或取回原圖後未重跑 genFigs 即不同） | 全部相同 |
| 測試字樣 | grep `e2e`、「標準圖」「紅框」「測試」（畫面原文除外） | 0 |

## 2. docx 層核對（不憑回傳值）

通用作法（實體檔與時間戳、抽 `word/document.xml`、先串接文字節點再計數、大括號殘留、媒體數與去重、首欄不換行之查法、殘留行程）與可重跑之腳本，依 skill[role-writer-report-convert-to-docx] 第 7 節與其 `references/verification.md`。本節只留手冊之判準：

| 項 | 手冊之判準 |
|---|---|
| 圖題數 | ＝圖數 |
| 表題數 | ＝節數 |
| 圖引用「如圖N所示」數 | ＝圖數 |
| 表引用「如表N所示」數 | ＝節數 |
| 測試字樣（匹配「e2e」，在串接後之文字上加掃） | ＝0 |
| 首欄不換行 | 操作項目表之首欄 nowrap 設定生效 |

圖題數與表題數以不重複之編號計（手冊若啟用目錄，圖目錄、表目錄會再列一次）。

## 3. lint 與同步

- 專案 lint 掃描範圍含分冊子夾之 `src/` 與 `report/`；PASS 才交付。
- 為過 lint 或對帳而改動 spec 之 title／description：e2e 測試檔之 `it()` 標題同步改，並跑語法檢查；受影響之冊重跑 genMd → lint → genDocx → 本檔 §1～§2。
- L3 文件之版本紀錄登記本批新增之冊、圖數、新裁定之寫法（數字政策、入口捲動、暫時狀態、英文圖名之處理）。

## 4. 回報範本（五段固定，缺段即不完整）

```
【產出】<冊名>：<節數> 節／<圖數> 張；docx <大小>；路徑 <report/>
【回驗】genMd 零錯；lint PASS；document.xml：圖題/表題/引用皆吻合、無殘留、無測試字樣；媒體去重 <n/m>；無殘留文書行程
【spec 與測試檔改動】<案例>：<原載> → <改為>（依據：圖鍵 <…>）；受影響之冊已重產
【請裁示】（只放業主不決定就無法往下做者；每條寫「不決定則卡在哪一步」）
【知悉】（已依既有原則決定之寫法、非缺陷之畫面實況、規則之自然結果；不需回覆）
```

## 5. 裁示衛生（列「請裁示」前之三問）

1. **業主不決定，我就做不下去嗎？** 能依既有原則（L3 文件、報告總則、本技能）自行決定者，決定後列「知悉」或不提。檔名怎麼描述、筆數怎麼寫、圖名用哪個語意，都屬此類。
2. **之前是否已裁示？** 查 L3 定稿句與版本紀錄、共用文件之裁決表與待裁示彙整、專案記憶；已裁示者一律不重提（如「紅框在紅色按鈕上不可辨，暫不處理」）。
3. **若涉權限，是哪一軸？** 「無畫面權限」與「資料可讀」是兩件事，分開陳述；資料軸依表類別之規則開放者是設計事實，不是裁示項。

常見誤列：連續相同之兩張圖（工具列收合等反應元素即下一步目標者，為規則之自然結果；收合後框到開啟鈕者則屬框錯對象，退回 e2e 端而非列裁示）、訊息圖上其他即時數值為載入前狀態（畫面實況）、產物檔名含日期之描述方式（撰寫者依原則決定）、docx 媒體去重（轉檔器行為）。

## 6. 暫停指令之處置

使用者要求「先暫停」「先看 docx」時：列出已可確認之冊與其節／圖數，停止產製新的 docx；已派出之撰寫可在背景續寫 content，但不跑 genDocx；回報時明列「已產」「撰寫中」「未開始」三類。

## 7. 審圖報告（供業主審標準圖之圖文對照；非交付文件）

使用者難以逐張開圖檔時，以同一管線產一份 md→docx 放暫存區（轉檔與核對依 skill[role-writer-report-convert-to-docx]）：首節寫審圖說明與本輪變動摘要（哪些案例新增、哪些因共通變動重產、各流程總圖數、認可前不跑比對）；每案例一節：spec 之操作描述、手冊敘述（已有者），每張圖之圖說為「圖名（圖鍵）　框住：<spec 視覺項括號句>」；末節抽數張因共通變動重產之圖並註明變動點。只收本輪新增／變動之案例；完整手冊另附路徑。產後核對圖數與圖說數（文字節點法，見該技能第 7 節）；報告放暫存區，不入交付目錄。
