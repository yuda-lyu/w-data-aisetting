# 編修與美化既有簡報

本檔為 SKILL.md〈標準工作流程〉第 0 步所指.兩種任務的界線不同, 先判定再動手;判定不了時, 只問使用者**一個**問題:[要保留原本的設計只改內容, 還是內容不動只重做版面?]

| 型態 | 改什麼 | 不改什麼 |
|---|---|---|
| 編修 | 指定頁之文字, 數據, 圖片, 備忘稿, 轉場;依計畫增刪或複製頁 | 原有設計, 母片與版面配置, 計畫外的頁 |
| 美化 | 版面, 層級, 留白, 節奏, 配色與字型之套用 | 每一個字, 頁數與頁序, 資料值 |
| 重做 | 每頁換新視覺或重新分頁 | ——改走新建流程, 舊檔只當材料 |

## 1. 共同的第一步:盤點

```bash
officecli view "$FILE" outline         # 頁數與標題
officecli view "$FILE" annotated       # 每頁之字型, 字級, 表格, 圖表
officecli get "$FILE" /                # 頁面尺寸(pt), 佈景主題之字型與色
officecli query "$FILE" slidelayout    # 可用之版面配置名稱
```

記下:頁面尺寸;佈景主題之字型與色;各頁實際最常用之字級與顏色(各頁覆寫很多時以實際出現次數為準, 佈景主題之值只當參考;字級最常出現者會混入標題, 圖說與圖表標籤, 要對照真正的內文段落);以及無法原生編輯的物件(SmartArt, OLE, 視訊音訊, 3D 模型).

## 2. 編修:保留原設計

**動工前計畫, 經使用者確認才動手**:輸出頁序 → 對應之來源頁 → 沿用 / 修改 / 複製 / 捨棄(修改與捨棄各附一行理由);哪份材料放在哪一頁, 哪些材料因沒有合適的版面而捨棄.

1. **只動計畫內的頁.** 計畫外的頁不開啟寫入.
2. **就地修改, 保留身分.** 以 `set` 改既有圖形之文字, 顏色, 位置——圖形 id 不變, 其動畫與 Morph 配對才會存活;移除再重加會讓動畫失去目標.
3. **母片與版面配置上的物件不碰**——改了會影響所有套用該版面的頁;母片, 版面配置與頁面尺寸不在編修範圍.
4. **無法原生編輯的物件**(SmartArt, OLE, 媒體, 3D 模型)不改其內容;可以整個保留, 或經使用者同意整個移除.
5. **文字替換依[槽]的容量**——以框的幾何與字級估算, 不以舊文字的長度為準.放不下時依序:改寫精簡 → 拆到另一頁 → 改用較大的來源版面;不以縮小字級解決(與 SKILL.md〈改寫可以, 改內容不行〉一致).封面與章節頁只換標題, 副標, 作者與段標.
6. **新增頁**以最接近的來源頁複製(`officecli add "$FILE" / --from "/slide[N]"`), 清掉其頁面本身的內容後再寫入.
7. **圖片**換來源檔, 但保留原框之位置與尺寸;**表格與圖表**只改儲存格文字與數據值, 保留格式.
8. **內容事實**全部來自使用者的材料, 每一頁在計畫中註明來源;沒有來源的頁捨棄.範本上的佔位文字不得留成內容.只有主題沒有材料時, 先向使用者要材料.
9. **超連結**:頁序變動後, 簡報內的跳頁連結要重新指到正確的頁;對不到唯一目標就回報, 不要指到錯頁.
10. **改完回讀驗證**:頁數等於計畫;每頁之標題與替換文字都在(`view text`);備忘稿之數量與計畫相符;再走 SKILL.md 之 QA.
11. **第二輪修改**以已交付的檔為新的來源重新盤點, 不沿用上一輪的記憶.

## 3. 美化:內容凍結, 只重做版面

1. **每一個字逐字保留**——不增, 不刪, 不改寫, 不重排.原稿以粗體或顏色強調的詞, 在新版面中仍要突出(換成新配色).
2. **頁數與頁序 1:1.** 要拆開擁擠的頁或合併頁, 就不是美化.判準:原本的分頁是要保留的資訊, 還是前作者要被改進的結構?後者改走新建流程.
3. **不加原稿沒有的頁面裝飾**:頁碼, 頁尾, 每頁重複的標題帶都不加.
4. **資料值凍結.** 圖表與表格可以重新排版與配色, 數值不動.
5. **過滿的頁只能在頁內改善**(版面, 層級, 留白);仍嫌擁擠就在回報中標出, 建議使用者拆頁, 不要自行拆.
6. **身分來源**:佈景主題之色與字, 以及各頁實際覆寫之色與字, 兩者都列為候選, 說明採用哪一個與理由, 經使用者確認.
7. **驗證**:逐頁以 `officecli view "$FILE" text --start N --end N` 讀新舊頁之文字, 去除空白後比對——原稿每一個字串都要出現在對應頁;新頁不得出現原稿沒有的字(新增字數須為 0);頁數等於原稿.再走 SKILL.md 之 QA.
