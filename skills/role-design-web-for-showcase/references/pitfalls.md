# 典型錯誤形狀對照

每列皆為整理自實際指正之典型錯誤形狀(已去識別).自審時逐列問「我這張圖有沒有這個形狀」.標「預設」者,委託方或專案另有明確要求時從其要求.

## 定位與流程

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 把投影片之滿版報頭用在報告圖 | 讀者一眼看出是投影片貼進報告,會被認為偷懶 | 先問成品放哪裡;標題只佔左上角一列 |
| 「重新設計」只換色或加色條 | 換個殼不等於設計 | 上網調研,查對應用途之作法,附來源 |
| 舉例沿用現成畫面,未對齊本期核心 | 一眼看出沒提取核心 | 先提取核心;沒有就依 skill[role-coder-for-test-e2e] 新增案例與標準圖(須先取得使用者授權) |
| 圖內畫面用現場截圖或另拍 | 失去「已測試」之證據 | 直接引用標準圖,裁切避開紅框 |
| 把圖交給使用者說「待你審」 | 把審查外包 | 自己先審,再給檢視頁 |
| 指出一處只改一處 | 同類還在,下一輪又被指 | 歸類後全掃同類(圖、圖名、報告、規格、手冊) |
| 規則只記在圖端或報告端之一 | 下次又不參考 | 用字規則共用一份,圖內文字套同一份 lint |

## 文字

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 「逐時 JSON」時間接資料格式 | 不知道要傳達什麼 | 直接寫畫面能做什麼 |
| 「雙線性內插」「某格式檢核」 | 一般技術;審查委員會問別的格式就不能嗎 | 寫做了什麼:檢核有效數值、換算為目標量 |
| 「快約 1 倍」「約 50%」(預設) | 會被要求舉證,明年也會被拿來比 | 「大幅提升」;實測數字只放測試報告 |
| 寫排程週期(預設) | 週期是觸發不是完成,會被當標準 | 「以定時排程觸發」 |
| 「已使用 N 筆」 | 讀者會問其他為何不用,也沒說到系統有篩選 | 「有效 N 筆,經品質檢核挑選」 |
| N 旁邊寫「全部」 | 讀成全部只有 N | 「全部有效」連寫,數量退為說明 |
| 小標題寫「大幅提升」或純數量 | 單獨讀不懂,敘述機制不一 | 「系統效能提升」,數量放說明 |
| 標題寫期別年度 | 報告本身即該期,稀釋注意力 | 提煉系統之亮點 |
| 標題截成「整體效能成果」 | 意思跑掉 | 「整體效能提升成果」 |
| 用遊戲等領域用語描述系統能力 | 被誤解為能力較低 | 查證定義,改用正確說法 |
| 寫品質不佳、無效項目數 | 讀來推卸、指責委託方 | 從本案有品質檢核出發,不列其餘數量 |

## 標題

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 「某功能:敘述」 | 報告內文搬上來 | 一句完整主張 + 灰色副標 |
| 左側色條加文字 | 太常見,等於沒設計 | 圓形圖示 + 主張句 |
| 貼齊邊界之滿版色帶 | 投影片式 | 左上角獨立一列 |
| 標題放右欄上方 | 與主要文字區擠在一起,沒有層次 | 一律左上角,右側留白 |
| 標題圖示用強調色 | 體積大,被當成焦點 | 標題主色,圓底用其淺色 |

## 色彩

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 手段區塊整片強調色 | 讀者認定該區最重要,擠壓真正之亮點 | 手段用次要色,實底合計不超過 10% |
| 核心與外圍同色 | 核心失去主角地位 | 實色只給核心,外圍中性底 |
| 實底襯白字,底內又有白框 | 注意力被底色與小框分攤 | 強調句用強調色大字,技術退為灰字 |
| 同區 2 個大數字同為強調色 | 互搶 | 次要者換中性色 |
| 紅底黃字 | 對比差,捨本逐末 | 重要字用白字,次要才退色 |
| 藍配深橘 | 色相大跳 | 近似色依序變化 |
| 紅至粉紅 | 色階稀薄 | 色相跨度約 40~100 度 |
| 深藍至藍綠配紅色主角 | 不搭且面積大,主色被稀釋 | 輔色取主色之相鄰色相,面積縮小 |
| 文字描述配色來回多輪 | 主觀參數難以言傳 | 給選色器讓使用者直接選 |
| 文字以白底框蓋圖 | 讀起來像挖空 | 放圖之空曠處或白底上 |

## 版面

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 只求底線一致(左小、中多格、右高) | 沒有主角 | 單一主角,其餘依序縮小 |
| 相鄰區塊同排版 | 看起來沒設計過 | 分區塊,不同配色或風格 |
| 右欄單獨升至頂端以填滿標題右側 | 大矩形高低差一眼可見 | 上下緣對齊,標題右側留白 |
| 子區塊間距大於大區塊 | 層次顛倒 | 大 16、子 12;等比放大填寬 |
| 同階標題 70、64、34 混雜 | 看起來沒仔細調整 | 同階同字級,主要亮點才大一階 |
| 核心內上下排同字級 | 沒有重點,也不合圓形 | 重點最大,依弦長遞減 |
| 高亮橫帶內大字偏上 5 像素 | 聚焦處之誤差最顯眼 | 以墨跡量測校正 |
| 符號用字元(→) | 字級不同而偏下 | svg 置於 flex 列 |
| 多格畫面被裁一半 | 失去原意 | 先由長寬比定尺寸 |
| 圖示下塞標題與文字 | 右邊大量留白 | 圖示與標題同列,說明佔滿全寬 |
| 放射連線長短不一 | 看起來沒細心安排 | 等長等角 |
| 主要對象偏離、空白過多 | 浪費展示空間 | 依扣除圖例後之可見範圍置放 |

## 圖示

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 田字形接「4 個…」 | 讀成「田 4」 | 連同文字看 |
| 半圓儀表 | 下方開口讀成被裁切 | 完整圖形 |
| 閃電代表任何效能、燈泡代表任何改善 | 通用符號不傳達主題意含 | 查意象後自繪 |

## 檢核程式本身

| 錯誤形狀 | 為何不行 | 正解 |
|---|---|---|
| 新增圖示時弄壞載入,全部圖示消失而檢核仍通過 | 量不到就不報 | 加「未渲染」之判定 |
| 每塊只取最小間距 | 小的一向蓋掉大的一向 | 水平與垂直各取最近鄰 |
| 新檢核未以壞版本實跑 | 不知道抓不抓得到 | 先紅後綠 |
